
A modern and responsive personal portfolio built with **React**, **Tailwind CSS**, and **Framer Motion**, showcasing projects, skills, certifications, and experience.

## Features

- Responsive design (mobile-first)
- Dark theme with toggle support
- Smooth animations with Framer Motion
- Custom cursor effect
- Contact form with validation
- Certifications section with Credly links
- SEO optimized
- Accessibility support
- Vercel deployment
